# 🎮 OUT-OF-SIGHT (GAMJAM) — Game top-down (Prototype)

Mô tả ngắn  
OUT-OF-SIGHT là prototype top-down nhỏ làm bằng Unity: Người chơi di chuyển ngoài tầm nhìn của quái để ám sát, tiêu diệt toàn bộ kẻ địch

## ➤ Tính năng chính
- Di chuyển người chơi bằng phím mũi tên 
- Quái tuần tra, phát hiện và đuổi
- Bắn gây sát thương
- UI HP và đếm quái 
- Màn Victory / Defeat 

---

## ⚙️ Yêu cầu
- Unity Editor (khuyến nghị 2020.3 LTS hoặc mới hơn)  
- TextMeshPro (package)  
- DOTween (nếu dùng animation chết)  
- Universal RP (nếu dùng `Light2D`) — nếu không, loại bỏ/disable phần Light2D

---

## ➤ Điều khiển
- Phím mũi tên: di chuyển (Right / Left / Up / Down).  
- Va chạm quái để "chiến đấu"
